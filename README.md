- Configured underwriting and approval routing for high-risk policies and claims.
- Built custom Lightning Web Components for policy and claims dashboards.

**Tech:** Salesforce · Apex · LWC · Record-Triggered Flow · Approval Processes

- Developed an automated loan evaluation and approval workflow.

**Tech:** Java 21 · Spring Boot 3.x · Apache Kafka · Kubernetes · PostgreSQL · Redis

- Designed a prototype for decentralized railway signaling and route management.
- Used event-driven telemetry streaming with Apache Kafka.

### 4. Multilevel Approval-Based Booking System

**Tech:** Java · Spring Boot · MySQL · Docker · Kubernetes · Flutter

- Designed a multilevel approval workflow for institutional resource bookings.
- Modeled the approval hierarchy: **HOD → Principal → Director → MD**.
- Implemented role-based authentication and authorization.
- Enabled approve, reject, and forward actions at each level.
