## 🚀 Featured Projects

### 1. Salesforce Insurance Policy & Claims Automation System
**Tech:** Salesforce Flow Builder · Apex · Lightning Web Components · Approval Processes

- Built an end-to-end insurance management workflow on Salesforce CRM.
- Created record-triggered flows for policy activation and premium generation.
- Automated premium payment tracking and overdue-payment handling with scheduled flows.
- Implemented claim lifecycle workflows for submission, approval, rejection, and settlement.
- Configured underwriting and approval routing for high-risk policies and claims.
- Developed custom Lightning Web Components for policy and claims dashboards.

### 2. Loan Approval System — Salesforce
**Tech:** Salesforce · Apex · Lightning Web Components · Record-Triggered Flow

- Developed an automated loan evaluation and approval workflow.
- Used decision logic to classify applications as approved, pending, or rejected based on credit score, salary, loan amount, and debt.
- Built Lightning record pages and components for status tracking and data visualization.
- Automated parts of the approval workflow to reduce manual review effort.

### 3. Decentralized Railway Signaling & Route Management System
**Tech:** Java 21 · Spring Boot 3.x · Apache Kafka · Kubernetes · PostgreSQL · Redis

- Designed a prototype for decentralized railway signaling and route management across station and zonal operations.
- Used event-driven telemetry streaming with Apache Kafka.
- Project targets included sub-500 ms regional API latency and 99.99% availability under simulated high-traffic load.

### 4. Multilevel Approval-Based Booking System
**Tech:** Java · Spring Boot · MySQL · Docker · Kubernetes · Flutter

- Designed a multilevel approval workflow for institutional resource bookings.
- Modeled a role-based approval hierarchy: **HOD → Principal → Director → MD**.
- Implemented role-based login, authentication, and authorization.
- Supported dynamic request routing with approve, reject, and forward actions at each level.

### 5. KaushalyaKarnataka — Local Services Marketplace
**Tech:** Android · Kotlin · Firebase / Firestore

- Includes service listings, category-based discovery, worker portfolios, booking flow, and customer reviews.
